# Initial Planning

## Objective

Create a complete and playable Pac-Man game in Python.

## Phase 1 — Project setup

- Create the project architecture
- Configure `uv`
- Add Pygame
- Add flake8, mypy and pytest
- Create the Makefile
- Create the configuration file

## Phase 2 — Core structures

- Create positions and directions
- Create the internal maze representation
- Create player, ghost and collectible entities
- Implement collision helpers

## Phase 3 — Gameplay

- Integrate the external A-Maze-ing package
- Generate levels
- Move the player
- Move ghosts automatically
- Add pacgums and super-pacgums
- Add score and lives
- Add level timers
- Add level progression

## Phase 4 — User interface

- Create the main menu
- Create the game screen
- Create the pause menu
- Create the game-over screen
- Create the victory screen
- Create the name-entry screen
- Display highscores

## Phase 5 — Finalisation

- Add cheat mode
- Add unit tests
- Run flake8
- Run mypy
- Run pytest
- Complete the README
- Package the application
- Publish the game
